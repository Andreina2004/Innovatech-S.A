# Innovatech S.A. - Sistema Multiplataforma

Repositorio oficial del proyecto **Innovatech S.A.** Desarrollado como solución integral de taller práctico, integrando una aplicación móvil multiplataforma y un servidor backend robusto.

---

## 🛠️ Tecnologías Utilizadas

### Frontend (Cliente Móvil)

- **React Native / Expo** (Framework multiplataforma)
- **TypeScript** (Tipado estático)
- **Expo Router / Navigation**

### Backend (Servidor y API)

- **Node.js** con **Express**
- **TypeScript**
- **Prisma ORM** con base de datos SQLite

---

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado de la siguiente manera en la raíz:

- `src/` - Código fuente de la aplicación móvil (frontend).
- `INNOVATECH_Backend/` - Servidor backend, rutas de la API, controladores y esquemas de base de datos.
- `app.json` / `package.json` - Configuraciones generales del cliente móvil.

---

## Cómo Ejecutar el Proyecto en Local

### 1. Iniciar el Backend

Abre una terminal independiente, entra a la carpeta del servidor y arráncalo:

```bash
cd INNOVATECH_Backend
npm install
npm run dev
```
